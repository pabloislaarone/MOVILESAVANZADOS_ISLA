Repositorio del ciclo completo. Cada semana tiene su propia carpeta (`SEMANA01` a `SEMANA16`) y el trabajo se organiza por ramas.

## Ramas

| Rama | Contenido |
|---|---|
| `main` | Solo la estructura y este README |
| `manual` | Ejercicios resueltos a mano, sin IA |
| `ai-assisted` | Ejercicios resueltos con apoyo de IA (incluye `PROMPTS.md`) |
| `practicas` | Prácticas calificadas |
| `demo01` | Pruebas |

## Estructura

```
SEMANA01/
SEMANA02/
...
SEMANA16/
```

Para ver los ejercicios de una semana, cambia a la rama `manual`, `ai-assisted` o `practicas` y entra a su carpeta.
